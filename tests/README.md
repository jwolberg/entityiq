# tests/

This directory is reserved for cross-cutting and end-to-end tests that span
both the backend and frontend (e.g., integration tests, E2E flows).

Unit and component tests live alongside their source in `backend/` and
`frontend/` respectively.

Test harness configuration (pytest, vitest, CI) will be set up in
**P0-T3 (Lint, test harness, and CI)**.
